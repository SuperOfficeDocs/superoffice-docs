# Mobile CRM 11.1.16 update

## VoiceNote - voice-to-text notes on appointments

Capturing meeting notes without typing is possible directly from an appointment: dictate the note, and an automatic artificial intelligence (AI) refinement step cleans it up - removing filler words, adding punctuation, and tightening repetition - before it's ready to save.

In the task menu of an appointment's **Edit agenda** or **Edit internal notes** screen, select **Add voice note**, then stop recording when done. The refined text is shown for review and can be edited before it's appended to the appointment's **Agenda**.

![Task menu on the Agenda screen showing the Add voice note option -app-screen][img1]

## Get started - a clear welcome screen for logging in

The Mobile CRM welcome screen is built for clarity: rounded elements, theme-aware colours, and strong contrast make it easy to read whether the device is set to light or dark mode.

The welcome screen appears when opening Mobile CRM, offering Log in now or, for anyone who needs to connect the app to a SuperOffice installation first, "Are you an Onsite customer".

Tapping **Are you an Onsite customer?**  allows the user to connect Mobile CRM to a onsite SuperOffice installation: by entering the server URL and tapping **Connect**.

![Welcome screen and Need help to log in screen, side by side -app-screen][img2]
