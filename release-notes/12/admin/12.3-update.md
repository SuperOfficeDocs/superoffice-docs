# Settings and maintenance 12.3 update

## Multiple DKIM for Mailgun

**Send outgoing mail from several domains - such as separate brands or country-specific addresses - with each domain signed by its own DKIM key instead of sharing one key across the tenant.**

A tenant with a single DKIM key signs every outgoing mail with that one domain, even when a mailing goes out from a country-specific address or from the person in **Our contact**, which weakens DKIM and DMARC verification for any domain other than the one the key belongs to. Moving mail off Mailgun to work around this makes bounce and complaint handling harder, since there's no webhook back to SuperOffice Online to mark a mail as bounced, and bounces then have to be imported via the inbox instead.

Request a DKIM setup for each sending domain using the [Order DKIM][2] form, listing the domains involved - for example brand1.com, brand2.com, and brand3.no. SuperOffice Operations creates the domains in Mailgun, generates a DKIM key for each one, and sends you the DNS records to add. Your DNS administrator adds those records, following the [DKIM][3] and [SPF][4] setup guides, and once SuperOffice Operations confirms the records are valid, the domain is ready to use as a sending domain.

Learn more about [multiple DKIM records][1].

Where to order a new DKIM key:
[https://community.superoffice.com/order-dkim][2]
